# hotel · RollingGo 酒店插件

连接 RollingGo，在对话里搜索酒店、查看实时房型、创建待支付订单和查询订单；插件页负责服务安装、更新和登录，不需要 API Key。

## 页面

- 安装 / 更新酒店服务；
- 登录 RollingGo：自动打开授权链接，也可手动打开或复制；
- 退出登录；
- 查看运行环境、服务版本与登录状态；失败可就地重试，登录可取消。

## 工具

- `hotel_search`：按地点、日期、人数、星级搜索酒店，文本给出星级、参考价、距离、地址、标签、hotelId 与预订链接；
- `hotel_detail`：按房型归并价格方案，逐方案给出每晚均价、按入离日期计算的总价、床型、早餐、取消政策、价格方案 ID、入离日期与房间信息（面积/楼层/可住人数/窗/网络）；卡片一行一个房型，显示最低总价、每晚均价、方案数与取消政策；
- `hotel_book`：用户确认后锁价并创建待支付订单，返回官方支付链接；可选 `rate_plan_id`，同一房型有多个方案时会弹出原生选择；
- `hotel_orders`：查看订单号、房型、日期、状态、支付状态和总价。

搜索和房型只读；预订前会弹出原生确认，只创建待支付订单，支付由用户在 RollingGo 完成。RollingGo 房型报价返回的是每晚均价，插件按入住/离店日期换算为整段总价；房型结果按房型归并展示，一行一个房型并标出最低总价与方案数。

## 技能

`deepdeep-hotel` 指导 Agent 优先使用上述工具；用户明确确认酒店、房型、价格方案、日期和总价，并提供联系人信息后，才调用 `hotel_book` 锁价并创建待支付订单；同一房型有多个价格方案时让用户明确选择并把价格方案 ID 传给 `hotel_book`。插件不代替用户支付。
